Website Audit

Enter a client's web address. It checks speed, accessibility, SEO, security, domain, hosting and technology, then builds a PDF report. All free data sources.

Without a key, Google's shared free quota often returns "429" and the speed test fails. Get a free key: Google Cloud Console, create a project, enable "PageSpeed Insights API", then Credentials, Create API key. No billing needed.

Advanced

Free public proxies are often blocked or rate limited (an HTTP 401 or 403 means that). For reliable results, host your own proxy (a free Cloudflare Worker takes five minutes) and put its address first. The proxy is only needed for on-page checks such as titles and headings; speed, accessibility, SEO score and technology detection work without it.
